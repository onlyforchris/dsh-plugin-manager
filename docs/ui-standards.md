# UI 标准

> 本文件是 `AGENTS.md` 引用的完整 UI 规范。通用版（跨项目）见团队文档库《UI标准-通用.md》。

## 硬性禁止

1. **禁止面板/卡片左侧或顶部装饰色条**（`border-left: 3px solid` 高亮竖条、顶部渐变条、角标色块）。层级用边框、圆角、留白表达。
2. **禁止渐变装饰**：背景、按钮、卡片、图标底座一律纯色；功能动效（如进度条）也优先纯色。
3. **禁止彩色描边堆砌**：状态用「底色 + 文字色」小徽章，不加彩色边框。
4. **禁止装饰性 emoji/图标彩底**：图标随宿主风格。
5. **禁止发光/光晕阴影**：阴影克制，hover 提升 ≤ `0 4px 12px`。

## 应该做的

- 颜色、圆角、间距、字体一律用宿主设计令牌（DSH：`--dpm-*` 变量、`Canvas`/`CanvasText`）。
- 语义色固定一套：成功绿 / 警告琥珀 / 危险红 / 强调 accent，不随意新增。
- 信息层级靠中性色（`CanvasText` 3%–6% 底色、1px 边框、字号字重）。
- 动效 ≤300ms 淡入/位移；hover 只变边框、底色、阴影。
- 圆角统一：卡片 12–16px、控件 8–10px、徽章全圆。

## 验收清单（提交前自查）

- [ ] 无面板左侧/顶部装饰色条
- [ ] 无 `linear-gradient`
- [ ] 颜色全部来自令牌或语义色
- [ ] 深色/浅色主题可读
- [ ] 状态色全程一致
- [ ] 无缩放弹跳、无发光
- [ ] 整体观感贴近平台原生
